# Code of Conduct

## Our pledge

We aim for a welcoming, respectful community around Hearth — contributors, users, and maintainers alike.

## Expected behavior

- Be kind and constructive in issues, PRs, and discussions
- Assume good intent; disagree on ideas, not people
- Respect privacy and the local-first mission of the project

## Unacceptable behavior

- Harassment, hate speech, or personal attacks
- Publishing others’ private information
- Spam or sustained disruption

## Enforcement

Maintainers may moderate comments, close issues, or block contributors who violate this code.  
Report concerns via GitHub issues (or privately to maintainers if the repo provides a security contact).

## Scope

This Code applies in project spaces (GitHub issues, PRs, discussions) and when representing the project publicly.
